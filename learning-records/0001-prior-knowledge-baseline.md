# Prior Knowledge Baseline: Experienced Programmer New to C# and .NET

The learner is an experienced developer coming from other programming languages (such as TypeScript, Python, or Java) who is new to C# and the .NET 10 ecosystem.

## Implications
- Do not spend time explaining general programming fundamentals (what a database table, unit test, interface, or HTTP request is).
- Focus directly on translating familiar programming mental models into modern C# 12+ / .NET 10 syntax and idioms used in this repo: positional `record` declarations, file-scoped namespaces, collection expressions (`[...]`), raw string literals (`"""..."""`), `Task<T>` + `CancellationToken`, and `await using` (`IAsyncDisposable`).
