# C# and .NET as the Cross-Platform Technology Stack

We choose C# and the .NET ecosystem to build the multiplatform application targeting Desktop (Windows, macOS, Linux) and Mobile (iOS, Android). .NET provides robust enterprise-grade HTTP networking, native Microsoft authentication/MSAL libraries, performant SQLite integration via Microsoft.Data.Sqlite / EF Core, and first-class native multiplatform UI frameworks.

## Status

Accepted

## Considered Options

- **Rust / Tauri v2**: Discarded to standardize entirely on C# and .NET.
- **Dart / Flutter**: Discarded to remain within the .NET ecosystem.
- **C# / .NET**: Chosen for seamless Microsoft ecosystem compatibility, strong typing, mature concurrency, and enterprise readiness.
