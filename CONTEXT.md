# M365 Copilot Chat Exporter

A multiplatform application enabling Microsoft 365 Copilot enterprise users to browse, select, and export their conversation history into readable and archival formats.

## Language

**Conversation**:
A single continuous dialogue session between a user and Copilot in Microsoft 365 Chat (BizChat).
_Avoid_: Thread, chat room, channel, topic

**Turn**:
A single exchange within a conversation consisting of one user prompt and Copilot's corresponding response.
_Avoid_: Message pair, interaction, step

**Prompt**:
The user's input or instruction sent to Copilot within a turn.
_Avoid_: Query, question, user message

**Response**:
The answer and synthesized content generated by Copilot within a turn.
_Avoid_: Output, completion, assistant message

**Citation**:
A reference link attached to a response pointing to an enterprise document (SharePoint, OneDrive) or external web page used for grounding.
_Avoid_: Source link, attribution, reference, footnote link

**Catalog**:
The searchable and filterable collection of conversations retrieved from the user's account.
_Avoid_: Chat list, history list, conversation index

**Export Bundle**:
The organized set of generated files (Markdown, HTML, JSON, and master index) produced from a selected set of conversations.
_Avoid_: Dump, archive, backup, export package

**Sync**:
The process of fetching and reconciling remote conversation metadata and turns from Microsoft 365 into the local catalog.
_Avoid_: Refresh, pull, download, fetch

**Session**:
The authenticated connection state established between the application and Microsoft 365 via the embedded webview.
_Avoid_: Token, login state, connection, credentials
